02 — current best algorithm

What ships as the default engine today

A three-stage pipeline behind rna_draw's checker-gated layout_guaranteed. It reuses ViennaRNA's RNApuzzler (vendored, in-process) and never trusts it blindly — an independent overlap checker is the arbiter at every step.

05 — what's left

The remaining frontier

The core goal is met: rna_draw's default never draws a silent overlap. What remains is making the hardest tail prettier, not correct.

The deep-rRNA tail

~37 giant structures mix local crowding with distant branch collisions that local rigid moves can't coordinate away. They get the guaranteed-clean circle fallback today.

next: constructive envelope engine → compact clean layouts by construction

Empty-loop inputs

14 structures contain a degenerate () loop that hangs RNApuzzler unconditionally. They are guarded and routed to the safe fallback — correct, but not conventional.

next: handle the zero-length loop in the vendored resolver
